# Alunixa X v1.0.49

## 中文

- 修复 macOS x64 CI 在生成 DMG 后卸载私有构建设备的竞态：普通卸载和强制卸载仍使用有界重试，最后仅对本次构建镜像执行懒卸载并再次确认设备状态。
- 保留 v1.0.42 经典主界面、离线字体、面板和窄窗口模型卡片布局。
- 修复“重启 Codex”只唤醒旧窗口的问题：使用当前会话实际调试端口，并在 CDP 不可用时确认目标桌面进程退出后再启动。
- Windows 重启按应用映像、命令行和进程句柄确认唯一目标，不误停其他隔离实例或 CLI。
- 保留高级供应商、逐模型协议/上下文/压缩阈值、请求日志、代理、Agent 协作、Skills、MCP、增强和保存冲突保护。

注入与托盘退出逻辑没有改动；配置、账号、会话、媒体和系统网络不会被重置。完整验证记录见[经典界面与重启回归报告](../reports/2026-10-23-classic-interface-restart.md)。

## English

- Fixes the macOS x64 CI race that could leave the private build DMG attached after packaging. Bounded normal/forced retries are followed by one lazy detach scoped to that build image and a final device-state check.
- Retains the v1.0.42 classic shell, bundled typography and narrow-window model cards.
- Fixes Restart Codex only activating the old window by using the session's actual debug port and confirming desktop-process exit when CDP is unavailable.
- Windows restart verifies executable identity, command-line arguments and the retained process handle, keeping other isolated instances and CLI processes untouched.
- Retains advanced providers, per-model protocol/context/compaction, request logs, proxies, agent collaboration, Skills, MCP, enhancements and save-conflict protection.

Injection and tray-exit behavior are unchanged. Configuration, accounts, conversations, media and system networking are not reset. See the [classic interface and restart verification report](../reports/2026-10-23-classic-interface-restart.md).

## Русский

- Исправлена гонка в CI macOS x64, из-за которой после упаковки мог оставаться подключённым частный DMG. После ограниченных обычных и принудительных повторов выполняется одна ленившая выгрузка только этого образа и финальная проверка состояния устройства.
- Сохранены классический интерфейс v1.0.42, встроенные шрифты и карточки моделей для узкого окна.
- Исправлен перезапуск Codex: используется фактический порт сеанса, а при недоступном CDP завершение целевого процесса проверяется до нового запуска.
- В Windows проверяются исполняемый файл, аргументы и сохранённый дескриптор; другие изолированные экземпляры и CLI не затрагиваются.
- Сохранены расширенные провайдеры, протокол/контекст/сжатие каждой модели, журнал запросов, прокси, взаимодействие агентов, Skills, MCP, улучшения и защита сохранения.

Внедрение и выход через трей не менялись. Настройки, аккаунты, сессии, медиа и системная сеть не сбрасываются. См. [отчёт о классическом интерфейсе и перезапуске](../reports/2026-10-23-classic-interface-restart.md).
