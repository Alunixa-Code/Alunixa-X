# Alunixa X v1.0.33 — 第三方模型 tool_search 兼容修复

## 中文

- 修复自动生成模型目录时，Claude、Gemini、GLM、DeepSeek、Grok 及其他无专属元数据模型误继承 GPT 的 `supports_search_tool=true`，导致 Codex 向不支持该类型的上游发送原生 `tool_search` 的问题。
- 自动回退模型现在声明 `supports_search_tool=false`，由 Codex 使用普通工具曝光路径，而不是在代理中粗暴删除工具定义、调用历史或请求字段。已知模型的专属能力、用户提供的显式模板和外部模型目录保持不变。
- 缓存策略、缓存创建/读取统计、流式响应处理和认证配置未修改；工具列表变化后，首次请求可能需要重新创建缓存，不保证沿用升级前的缓存命中。
- 增加上述五类模型及供应商前缀的目录回归；验证真实配置落盘、GPT 能力保留及 Claude 缓存统计。
- 安装后退出并通过 Alunixa X 重新启动 Codex，使管理器重新生成模型目录。已有外部自定义目录不被强制覆盖；若其中手工设置了不受上游支持的能力，需要单独修正。
- 本版修复的是已确认的能力误继承，不代表所有第三方网关的全部参数均支持；未用用户真实密钥逐家调用验收，不删除会话、供应商或密钥。

## Русский

- Исправлено ошибочное наследование `supports_search_tool=true` от GPT для автоматически создаваемых записей Claude, Gemini, GLM, DeepSeek, Grok и других моделей без собственных метаданных.
- Для резервных записей теперь используется `false`: Codex предоставляет обычные инструменты напрямую. Определения инструментов, история вызовов и поля запросов не удаляются. Явные пользовательские шаблоны, внешние каталоги и возможности известных моделей сохраняются.
- Политика кэширования, статистика создания/чтения кэша, потоковые ответы и авторизация не изменены. После изменения списка инструментов первый запрос может создать новый кэш.
- После установки закройте Codex и запустите его через Alunixa X для обновления каталога. Внешние пользовательские каталоги не перезаписываются.
- Это исправление конкретной ошибки метаданных, а не гарантия поддержки всех параметров всеми шлюзами. Проверки не использовали реальные ключи пользователя; сессии и провайдеры не удаляются.

## English

- Fixes fallback catalog entries for Claude, Gemini, GLM, DeepSeek, Grok and other models without dedicated metadata incorrectly inheriting GPT's `supports_search_tool=true`.
- Fallback entries now declare `false`, allowing Codex's direct tool exposure path without stripping tool definitions, history or request fields. Known-model metadata, explicit user templates and external catalogs remain unchanged.
- Cache policy, cache creation/read accounting, streaming and authentication are unchanged. A changed tool list may require a new cache entry on the first request.
- After installing, close Codex and relaunch it through Alunixa X to regenerate the managed catalog. External user catalogs are not forcibly rewritten.
- Targeted tests cover all five model families, provider prefixes, catalog persistence, GPT capabilities and Claude cache accounting. This is not a claim of universal parameter compatibility or live validation against every provider.
