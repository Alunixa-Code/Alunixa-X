# Alunixa X v1.0.38 — Codex / Anthropic 本地协议修复

## 中文

- Responses ↔ Anthropic Messages 改为基于 CC Switch `99277921d9363c78e656ada0ca3bf39e30938b23` 的独立转换实现，不再绕经 Chat Completions；第三方许可已保留。
- 修复正式本地 HTTP 服务把 Anthropic 返回流交给 Chat 转换器的问题。流式、非流式、JSON 回退及上游返回 SSE 的非流式请求均使用正确入口，原生 Responses 保持透传。
- 普通 token 截断对话使用 Codex 可识别的 `response.completed` 收尾，同时保留 `status: incomplete` 和原因。截断工具不发布可执行完成事件，不完整压缩摘要不变成有效检查点。
- 修复恢复会话的开头角色、空文本、相邻消息和并行工具结果；保留原生内容块顺序、逐块收尾、思考签名分片和签名回放，兼容旧 AX 会话回放格式。
- 流式工具参数优先于起始输入，无增量时使用起始输入。命名空间、自定义工具和客户端工具搜索身份保持一致；长工具名使用稳定的 64 字节映射。
- 区分旧 Claude 思考预算和新版自适应思维，为正文保留预算空间，不发送冲突采样字段；强制工具选择不被静默放宽，缺少签名的续轮不错误启用思考。保留 AX 的 `xhigh` / `ultra` 自适应选择。
- Codex 缓存/会话元字段不误作 Anthropic 请求参数。保留缓存读取、创建和创建时长统计，并正确提供 Codex 的缓存写入 token 用量；原生搜索声明不伪造成可执行工具。
- 损坏编码/JSON、未知原生块、未完成流和超时仍明确失败；终态只发一次，不自动重放结果不明的上游请求。

### 验证与生效

- 新增转换专项、正式 HTTP 服务回归和可重复的隔离 CLI 验证工具，旧实现的转换与生产入口故障均已复现。
- 本机 **Codex CLI 0.157.1** 经真实 Helper 和本机模拟 Anthropic 网关完成普通 SSE、JSON/token 截断回退、带签名的工具调用续轮，实际客户端也确认缓存读取/写入用量。
- 正式 GitHub Actions 对 Windows x64、macOS x64、macOS arm64 执行测试与构建，发布六安装资产及 `latest.json`；发行页包含来源和 SHA-256。
- 不清空用户供应商、密钥、配置或会话，不修改系统代理，也没有自动安装或重启正在运行的 Codex。安装新版后完整退出旧实例，再通过 Alunixa X 启动；真实网关能力仍取决于其接口。

## English

- Replaced the Responses ↔ Anthropic bridge with an independent adapter from CC Switch commit `99277921d9363c78e656ada0ca3bf39e30938b23`, preserving its MIT notice and removing the intermediate Chat conversion.
- Fixed production HTTP dispatch for Anthropic SSE, ordinary JSON, JSON fallback, and unexpected SSE for non-streaming requests. Native Responses remain pass-through.
- Token-limited turns finish with Codex-compatible `response.completed` framing while retaining incomplete status. Truncated tools never become executable; incomplete compaction summaries are rejected.
- Preserved native block order, block lifecycle, signature fragments, signed thinking replay, and legacy AX replay. Normalized resumed history and parallel tool results.
- Streamed tool input takes precedence over start-event input. Namespace, custom, and client tool-search identities survive conversion; long names receive stable bounded aliases.
- Corrected legacy thinking budgets, adaptive thinking, sampling, forced tool selection, and unsigned tool continuations. AX `xhigh` / `ultra` selections are preserved.
- Preserved cache reads, writes, lifetime-specific statistics, and actual Codex cache-write accounting. Transport metadata and unsupported native search advertisements do not become Anthropic options or fake executors.
- Invalid events, incomplete streams, and timeouts remain failures. Terminal events are emitted once, with no uncertain-request replay.
- Codex CLI **0.157.1** completed SSE, JSON/token-limit fallback, and signed tool continuation through the real Helper and an isolated loopback gateway. GitHub Actions tests and builds Windows x64 and both macOS architectures, with six installation assets plus `latest.json`, provenance, and SHA-256.
- No user configuration, credentials, sessions, system proxy settings, or running Codex instances were reset or changed. Install the update, exit the old instance, and launch through Alunixa X; provider-specific capabilities remain upstream-dependent.

## Русский

- Responses ↔ Anthropic заменён независимым адаптером CC Switch `99277921d9363c78e656ada0ca3bf39e30938b23`, без промежуточного Chat Completions и с сохранением лицензии MIT.
- Исправлена маршрутизация в рабочем HTTP-сервисе: SSE, JSON, резервный JSON и SSE для обычных запросов обрабатываются соответствующим адаптером; нативный Responses передаётся без изменений.
- При лимите токенов используется `response.completed` с сохранением статуса `incomplete`. Обрезанные инструменты не исполняются, неполные сводки сжатия отклоняются.
- Сохранены порядок и жизненный цикл блоков, фрагменты подписей, повторное воспроизведение размышлений и старый формат AX. Исправлены восстановленная история и параллельные результаты.
- Потоковые аргументы имеют приоритет над начальным содержимым. Сохраняются пространства имён, пользовательские инструменты и клиентский поиск; длинные имена получают стабильное ограниченное отображение.
- Исправлены бюджет старых Claude, адаптивный режим, несовместимые параметры генерации, принудительный выбор инструментов и продолжения без подписи; выбор AX `xhigh` / `ultra` сохранён.
- Сохранены чтение/запись кеша, длительности создания и учёт записи в Codex. Служебные поля и неподдерживаемые объявления поиска не превращаются в параметры Anthropic или фиктивные исполнители.
- Повреждённые события, незавершённые потоки и тайм-ауты остаются ошибками. Завершение выдаётся один раз, неоднозначные запросы автоматически не повторяются.
- Codex CLI **0.157.1** успешно завершил SSE, JSON с лимитом токенов и продолжение инструмента с подписью через настоящий Helper и изолированный локальный шлюз. GitHub Actions проверяет три платформы и публикует шесть установочных архивов и `latest.json` с SHA-256 и исходным коммитом.
- Настройки, ключи, сеансы, системный прокси и работающий Codex не изменялись. После установки завершите старый экземпляр и запустите Codex через Alunixa X; возможности стороннего шлюза определяются его интерфейсом.
