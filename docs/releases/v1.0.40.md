# Alunixa X v1.0.40 — 修复 Anthropic 文本选项转换报错

## 中文

### 本版修复

- 修复 Codex 发送 `text.verbosity` 时，本地 Responses → Anthropic 转换器在请求到达上游前返回 `Anthropic text options require a native provider configuration` 的问题。
- 接受 `low`、`medium`、`high` 三种合法文本详细程度，以及缺省、`null`、空文本选项和普通 `text` 输出格式。沿用 CC Switch 的兼容处理，不把 Anthropic 不支持的同名参数发送给 Messages，也不改写用户指令、系统前缀或缓存策略。
- 保留结构化输出边界：`json_object`、`json_schema`、未知字段和非法参数仍明确返回转换错误，不把需要保证的 JSON 约束静默丢弃。
- 保留独立的 Anthropic 原生转换、流完成事件、JSON 回退、签名思考/工具续轮、缓存读写用量，以及 v1.0.39 恢复的高级供应商和增强功能。其他协议不变。

### 验证与使用

- 新增七项文本选项回归，涵盖合法详略、空值、非法类型、未知选项、结构化格式和普通文本格式的额外约束；同时检查原有指令、工具、思考和消息转换保持一致。
- 正式 Helper HTTP 夹具覆盖六种文本选项与四种请求/上游 JSON-SSE 组合，共 24 个连接场景。
- 使用已安装 Codex CLI 0.157.1，通过隔离本地网关验证 `low`、`medium`、`high` 与 SSE、JSON 限额结束、签名工具续轮的九种组合。入口观察器只读取原始请求，不注入或改写 `text`；验证客户端正常完成及缓存读写统计。
- GitHub Actions 对 Windows x64、macOS x64、macOS arm64 执行完整回归并构建六份安装资产和 `latest.json`。
- 安装新版后，完整退出旧 Codex/Helper 实例，再经 Alunixa X 启动，使新的转换器生效；只修改供应商配置不会替换已经运行的旧服务。本次不自动安装或重启用户应用，不清空配置、供应商、密钥或会话，不修改系统代理。

## English

- Fixed the local Responses → Anthropic bridge rejecting valid Codex `text.verbosity` before sending a request upstream.
- Accepts `low`, `medium`, `high`, omitted/null/empty options, and ordinary `text` format. Like CC Switch, the bridge does not forward an unsupported verbosity field or rewrite instructions/cache prefixes.
- Structured JSON constraints, unknown text options, and malformed values still produce explicit conversion errors rather than silently losing required behavior.
- Preserves native Anthropic streaming, JSON fallback, signed thinking/tool continuations, cache accounting, advanced providers, and restored enhancements. Other protocols are unchanged.
- Seven new regressions, 24 production Helper HTTP combinations, and nine isolated real Codex CLI 0.157.1 flows cover all three verbosity levels and SSE/JSON-limit/signed-tool responses. The ingress observer never injects or changes text options.
- GitHub Actions runs full regressions and builds Windows x64/macOS x64/macOS arm64 packages. After installation, fully close the old Codex/Helper and relaunch through Alunixa X; running services do not receive this code merely by editing a provider. No automatic install/restart, user-data reset, or system-proxy changes.

## Русский

- Исправлен отказ локального моста Responses → Anthropic при допустимом `text.verbosity` в запросах Codex до обращения к серверу.
- Поддержаны `low`, `medium`, `high`, отсутствующие/пустые значения, `null` и обычный формат `text`. Как в CC Switch, неподдерживаемый параметр не передаётся в Messages; инструкции и префикс кеша не изменяются.
- Ограничения структурированного JSON, неизвестные текстовые параметры и неверные значения по-прежнему вызывают явную ошибку преобразования, а не молча удаляются.
- Сохранены нативный поток Anthropic, резервный JSON, подписанные блоки размышлений и продолжения инструментов, учёт чтения/записи кеша, расширенные поставщики и восстановленные функции. Другие протоколы не изменены.
- Добавлены семь проверок, 24 комбинации рабочего HTTP Helper и девять изолированных сценариев с установленным Codex CLI 0.157.1 для трёх уровней подробности, SSE, JSON с лимитом и подписанных инструментов. Наблюдатель входа не добавляет и не меняет текстовые параметры.
- GitHub Actions выполняет полные тесты и сборку для Windows x64/macOS x64/macOS arm64. После установки завершите старые Codex/Helper и запустите приложение через Alunixa X; изменение поставщика не обновляет код уже запущенной службы. Автоматическая установка, перезапуск, сброс пользовательских данных и изменение системного прокси не выполняются.
