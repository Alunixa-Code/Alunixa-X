# Alunixa X v1.0.45 — PR #1 优化、macOS DMG 与静态契约修复

## 中文

- 交付 PR #1 的 Fast 服务模式重试、native client/重新注入生命周期清理，以及已核验 Codex 版本白名单。
- 修复 macOS x64 DMG Finder 对中文隐藏应用的可见性命令导致镜像无法 detach 的问题。
- 更新 macOS 隐藏应用静态契约测试，验证 `.hidden` 与 `chflags hidden`，不再要求已删除的 Finder `set visible`。
- 完整 workspace、前端、安装器和三平台正式 Actions 通过后发布六项安装资产及 `latest.json`。
- v1.0.43 与 v1.0.44 候选均未发布；本版包含全部代码、测试和打包修复。

## English

- Ships PR #1 Fast-state retry, native-client/reinjection cleanup, and the verified Codex version allowlist.
- Fixes the macOS x64 DMG Finder visibility command that left the image unable to detach for the Chinese hidden app.
- Updates the macOS hidden-app contract test to verify `.hidden` and `chflags hidden` instead of the removed Finder `set visible` command.
- Full workspace, frontend, installer, and three-platform Actions gates pass before publishing six installers and `latest.json`.
- v1.0.43 and v1.0.44 candidates were not published; this release contains all code, test, and packaging fixes.

## Русский

- Выпущены retry Fast, очистка native client/reinjection и проверенный список версий Codex из PR #1.
- Исправлена команда Finder в macOS x64 DMG, из-за которой образ не отсоединялся для скрытого приложения с китайским именем.
- Статическая проверка скрытого приложения macOS теперь проверяет `.hidden` и `chflags hidden`, а не удалённую команду Finder `set visible`.
- Полные workspace/frontend/installer и три платформы Actions проходят перед публикацией шести установочных файлов и `latest.json`.
- Кандидаты v1.0.43 и v1.0.44 не публиковались; этот выпуск содержит все исправления кода, тестов и упаковки.
