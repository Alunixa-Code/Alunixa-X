# Alunixa X v1.0.11 · Codex 兼容修复与高级提示词自动恢复

本版本发布于 **Alunixa-Code/Alunixa-X 新仓库**，以 v1.0.10 为基线，不是旧 Codex+++ 仓库的迁移包或 v1.0.6 镜像喵~

## 重点修复：高级提示词不再因更新或能力保存丢失

- 每次通过 Alunixa X 启动 Codex，都会在所有配置同步结束后、启动 Codex 前检查高级提示词；开启功能或配置仍引用托管提示词时，缺失文件/引用会自动恢复喵~
- 托管位置为当前 `CODEX_HOME/TSC_ZYL_PJ/do_special.md`，未自定义 CODEX_HOME 时仍位于用户 `.codex` 目录；配置写入实际绝对路径，不再硬编码到另一份默认 HOME 喵~
- 现存正文优先保留；缺失/空文件依次使用 `do_special.md.last-good`、管理器已保存正文、基础模板恢复，只有没有可恢复的用户内容时才使用模板喵~
- 保存其他 Agent 能力不会拿旧设置覆盖直接编辑的正文；只有显式修改正文才替换内容，关闭开关仅停止引用而不删除文件，再开启保留原文喵~
- 支持局部更新与设置重载，保护自定义外部提示词引用，配置不可读或解析失败时不使用空默认覆盖原文件喵~

## Codex 更新兼容

- 修复模块发现反复扫描、dispatcher 多定时重试、终端失败缓存、扩展自身 DOM 变更循环喵~
- 插件过滤不再绑定旧压缩变量名；本产品托管市场使用非保留名 `alunixa-x-curated`，同步磁盘 manifest、配置、旧禁用选择和跨平台路径，用户自建市场不变喵~
- 新版 `model/list`、原生 `serviceTiers`、Fast 能力和纯 API 会话恢复 provider 规范化统一适配喵~
- 本地任务删除与撤销同步会话索引、目录数据库、revision 和新状态文件，支持索引独有任务与多库失败恢复，保留远端记录喵~
- 微信回复及实时进度按 thread/turn 关联，支持提前通知、正式完成、final_answer、失败/中断、重试与绝对超时；保留已有 CLI 自动回退、公开进度、节流与脱敏喵~
- Guardian 配置只修复明确不兼容的旧非布尔/非表值，合法布尔和结构化设置保留；Dream Skin 兼容等价路径并保护旧备份喵~

## 保留与验证

- 保留 v1.0.10 纯 API 本地上下文、持久笔记/历史、原生窗口切换，以及仪表盘用量统计、现有品牌、图标、供应商设置和新仓库更新源喵~
- 前端行为与源码契约、独立 Rust 回归覆盖提示词恢复/保存、事件状态机、插件、索引、多数据库和跨架构资产选择；正式 Actions 在 Windows x64、macOS x64、macOS arm64 运行完整前端/Rust 测试后构建喵~
- Windows 正式构建继续使用固定哈希的独立官方 CLI v0.153.4、本版本 companion 与 loopback 假 Responses API 验证未登录情况下的笔记写入、真实窗口切换、恢复笔记和历史检索喵~
- 本轮不连接、重启或热注入用户正在使用的 Codex/Helper/CDP/微信服务；只读安装资源审计、隔离测试和 CI 不等同于所有真实账号、供应商及未来版本都已验收喵~

## 安装

- 已使用 Alunixa X 的用户直接安装下方对应系统/架构的 v1.0.11 安装包，或在新管理器中检查更新，无需回到旧仓库重新迁移喵~
- 六项产物分别为 Windows x64 Setup/ZIP、macOS x64 DMG/ZIP、macOS arm64 DMG/ZIP；所有文件由本仓库 GitHub Actions 构建，提交来源与 SHA-256 见下文喵~
