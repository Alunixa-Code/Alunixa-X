# Alunixa X v1.0.46

## 中文

- 固定同步 CodexPlusPlus v1.5.0 (`23ed5515`) 至 v1.10.0 (`85f9117f`) 的非广告更新：核对完整 343 个提交、486 个变更路径及 816 个最终树文件，不追随之后的 main。
- 供应商支持命名 API Key 与切换、本机配置快照；改进聚合模型固定成员、默认成员官方登录、模型目录与分组，并保护分页编辑、未知字段及并发保存。
- 接入默认关闭的外部 Agent 协作、独立 CLI 和任务状态、MCP 注册后的运行时刷新、Skills 仓库与启停管理。
- 会话索引缓存、按页详情、文件流式备份与同步恢复日志；删除部分失败保留所有撤销信息，恢复前预检全部备份与索引冲突。
- 补入严格压缩完成判定、明文多代理数据、原始 `apply_patch` 输入和拒绝后的单次 exec 协商；保留 CC Switch 来源的独立 Anthropic 转换、合法文本选项、缓存统计、签名及工具身份。
- 用量状态栏按模型窗口计算，修复导航稳定性；增加原生 Fast 独立开关，保留旧 Fast 控制并补齐预热入口。
- 同步 Claude 检测/语音、多开隔离、真实下载与安装进度、DreamSkin 1.5.20 兼容及网站截图选择/滚动位置修复。
- 保留 AX 高级自定义供应商、每模型五协议/上下文/压缩阈值、已恢复的全部增强、独立生图与俄语。修复新文档尚无根节点时初始化中断，图片、GIF/APNG 和 MP4/WebM 仍使用完整媒体运行时。
- 不引入广告拉取、商业推荐或上游推广素材；[完整范围和验证记录](../reports/2026-10-21-upstream-v110-sync.md)明确列出适配与保留边界。

升级后完整退出旧 Codex/Helper，再通过 Alunixa X 启动以加载新本地服务与脚本；无需删除会话或重置供应商。外部 Agent 依赖本机可用的 CLI，语音依赖本机硬件和模型资源。安装包经 Windows x64、macOS x64/arm64 三平台 Actions 验证后发布，包含六项安装资产及 `latest.json`。

## English

- Integrates non-advertising changes from fixed CodexPlusPlus v1.5.0 (`23ed5515`) through v1.10.0 (`85f9117f`), auditing all 343 commits, 486 changed paths and 816 final-tree files without following later main commits.
- Adds named provider keys and local configuration snapshots; improves member-pinned aggregation, default-member official sign-in and grouped catalogs while preserving paged edits, unknown fields and concurrent-save protection.
- Adds opt-in external agent collaboration with independent CLIs/task status, MCP runtime refresh after registration, and Skills repository management.
- Adds cached/paged session reads, streaming backups and sync recovery journals. Partial deletion retains every undo reference; grouped recovery validates all manifests and index conflicts before restoring data.
- Integrates strict compaction completion, plaintext multi-agent payloads, raw `apply_patch` inputs and one-time rejected-exec negotiation. Preserves the independent CC Switch-derived Anthropic converter, valid text options, cache accounting, signatures and tool identities.
- Adds per-model usage status, navigation stability, an opt-in native Fast control and fixes legacy Fast prewarm handling without removing existing controls.
- Integrates Claude detection/dictation, isolated multi-instance fixes, actual download/install progress, DreamSkin 1.5.20 support, and selectable screenshots with stable scrolling.
- Preserves all restored enhancements, advanced per-model five-protocol/context/compaction settings, independent image profiles and Russian. Fixes initialization before a document root exists; image, GIF/APNG and MP4/WebM backgrounds retain the full media runtime.
- No advertising fetches, commercial recommendations or upstream promotional assets are added. See the [scope and verification record](../reports/2026-10-21-upstream-v110-sync.md).

Fully exit the old Codex/Helper and launch through Alunixa X after installing to load the new local service and scripts. No session deletion or provider reset is needed. External agents require locally available CLIs; dictation requires local hardware/model resources. Windows x64 and macOS x64/arm64 Actions gates precede publication of six installers and `latest.json`.

## Русский

- Интегрированы обновления без рекламы от фиксированной CodexPlusPlus v1.5.0 (`23ed5515`) до v1.10.0 (`85f9117f`): проверены 343 коммита, 486 изменённых путей и 816 файлов конечного дерева; более поздние коммиты main не включены.
- Добавлены именованные API-ключи и снимки локальной конфигурации, улучшены закрепление моделей за участниками агрегации, официальный вход участника по умолчанию и группировка каталога. Сохранена защита от потери полей и параллельных изменений.
- Добавлены отключённое по умолчанию взаимодействие внешних агентов, отдельные CLI и состояния задач, обновление MCP после регистрации и управление репозиториями Skills.
- Реализованы кэш и постраничная загрузка сессий, потоковые резервные копии и журнал восстановления синхронизации. При частичной ошибке сохраняются все ссылки отмены; до восстановления проверяются все копии и конфликты индекса.
- Перенесены строгая проверка завершения сжатия, открытые данные нескольких агентов, исходный ввод `apply_patch` и однократное согласование отклонённого exec. Сохранён независимый преобразователь Anthropic на основе CC Switch, допустимые текстовые параметры, кэш, подписи и идентификаторы инструментов.
- Добавлены строка расхода с учётом окна модели, устойчивость при навигации и отдельный переключатель нативного Fast; исправлен prewarm прежнего Fast без удаления существующих настроек.
- Перенесены исправления обнаружения Claude и диктовки, изоляции экземпляров, реального прогресса загрузки/установки, DreamSkin 1.5.20 и выбора снимков без скачков прокрутки.
- Сохранены все восстановленные улучшения, пять протоколов и отдельные контекст/сжатие модели, независимые профили изображений и русский интерфейс. Исправлена ранняя инициализация фона; изображения, GIF/APNG и MP4/WebM используют полноценную медиасистему.
- Реклама и коммерческие рекомендации не добавлены. Подробности: [отчёт о синхронизации и проверке](../reports/2026-10-21-upstream-v110-sync.md).

После установки полностью закройте прежние Codex/Helper и запустите Codex через Alunixa X. Удалять сессии или сбрасывать провайдеров не требуется. Внешним агентам нужны локальные CLI, диктовке — оборудование и ресурсы модели. Шесть установочных файлов и `latest.json` публикуются после проверок Actions на Windows x64 и macOS x64/arm64.
