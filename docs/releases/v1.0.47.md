# Alunixa X v1.0.47

## 中文

- 修复保存设置持续报“配置已被其他页面或程序修改”的根因：通用 IPC 包装器把正确的跨文件事务修订号替换成了设置文件自己的修订号。现在两层修订号独立传递、连续保存按前一次成功结果推进；不关闭 CAS、不自动用新修订号重试覆盖。
- 真正并发修改会保留未保存表单和显式原生能力编辑，原文件不覆盖。导入配置预览也返回当前事务修订号；设置路径迁移与多开状态目录保持隔离。
- 固定整合上游 CodexPlusPlus v1.10.1 `c541516c` 的非广告更新：完整核对 122 个提交、151 个变更路径、864 个最终树文件，不追随后续 main。
- 请求日志支持进行中状态、会话标题/筛选、真实首字耗时、token/缓存、根因与尝试详情；请求避震支持流式、旧流式、整段缓冲、首字提交窗口和有界过载重试，状态条通过本地桥接显示。
- 同步列表优先的项目会话、批量选择/项目全选/归档/搜索/分页保持，Skills 分组与批量启停，MCP 启动路径检查，外部 Agent 运行时限与错误处理。
- 同步供应商独立代理、CA 配置读取、逐模型思考参数/Lite/严格 Responses 历史、官方成员图片通道、原始补丁输入、桥接失联重注入及状态条不串会话等修复。
- 配置导入导出/路径迁移、登录启动/最小化、全局听写、Windows/原生 macOS 兼容与更新说明展示采用 AX 适配。语言在中英俄之间原地切换，不刷新或持久化包含凭据的草稿。
- 保留高级逐模型五协议/窗口/压缩、完整已恢复增强、独立 CC Switch 来源 Anthropic 转换、独立生图、图片/动画/视频、俄语及 AX 品牌；不导入广告、赞助拉取或上游品牌图标。
- 网页交互预览由当前 AX 管理器源码构建，使用内存演示配置，不调用真实本机服务。损坏 TOML/非 UTF-8 实时配置仍保护原始字节并明确失败，含糊或冲突工具历史不静默删改。

安装后完整退出旧 Codex/Helper，再从 Alunixa X 启动以加载新服务与脚本；无需删除会话或重建供应商。Windows x64、macOS x64/arm64 经正式 Actions 回归/构建后发布六项安装资产和 `latest.json`。范围与边界见[同步验证记录](../reports/2026-10-22-upstream-v1101-sync.md)。

## English

- Fixes persistent settings-save conflicts: the shared IPC wrapper replaced the correct multi-file transaction revision with the settings-file revision. Both revisions now remain distinct, and consecutive saves advance from the last confirmed result. CAS stays enabled; conflicts are never silently retried against newer data.
- Real concurrent edits retain the unsaved form and explicit native edits without overwriting current files. Import previews use the current transaction snapshot; settings-path migration remains isolated from multi-instance state.
- Integrates non-advertising changes through fixed CodexPlusPlus v1.10.1 `c541516c`: all 122 commits, 151 changed paths and 864 final-tree files, excluding later main commits.
- Adds request logs with live state, conversation filters/titles, real first-token timing, usage/cache and retry details; bounded overload handling supports streaming, legacy streaming and full buffering with a first-output commit window.
- Updates project/session lists, selection/archive/search/paging, Skills groups/batch actions, MCP startup checks and external-agent runtime limits.
- Integrates provider-scoped proxies, configured CA reads, per-model reasoning/Lite/strict Responses history, official-member images, raw patches and bridge/status-line recovery.
- Adds AX-adapted configuration export/import/migration, startup choices, global dictation, native Windows/macOS compatibility and release-note UI. Chinese/English/Russian switch without reload or storing credential-bearing drafts.
- Preserves all restored AX enhancements, advanced per-model five-protocol/context/compaction, independent CC Switch-derived Anthropic conversion, image-generation profiles and image/animation/video backgrounds. No upstream advertising or brand icons are imported.
- The public preview is built from current AX sources and uses memory-only demo state. Malformed/non-UTF-8 live configuration remains protected, and conflicting tool history is rejected instead of discarded.

Fully exit old Codex/Helper and launch through AX after installation. No session deletion or provider reset is needed. Three-platform Actions precede publication of six installers and `latest.json`. See the [scope and verification record](../reports/2026-10-22-upstream-v1101-sync.md).

## Русский

- Исправлены постоянные конфликты сохранения: общий IPC подменял ревизию многофайловой транзакции ревизией settings.json. Обе ревизии теперь независимы и обновляются после подтверждённого сохранения. CAS не отключается, конфликт не повторяется с новой ревизией автоматически.
- При реальном параллельном изменении сохраняются черновик и явные нативные настройки; текущие файлы не перезаписываются. Исправлены ревизия предварительного импорта и изоляция переноса настроек от отдельных экземпляров.
- Перенесены обновления без рекламы до фиксированной CodexPlusPlus v1.10.1 `c541516c`: 122 коммита, 151 изменённый путь и 864 файла конечного дерева; более поздний main не включён.
- Добавлены журнал запросов, текущие запросы, фильтры/названия сессий, реальное время первого токена, токены/кэш и подробности повторов. Обработка перегрузки поддерживает потоковый, старый потоковый и полностью буферизованный режимы с ограниченными повторами.
- Обновлены списки проектов/сессий, выбор/архивация/поиск/страницы, группы Skills и массовые действия, проверка запуска MCP и лимиты внешних агентов.
- Перенесены прокси провайдера, чтение заданного CA, параметры рассуждения/Lite/строгой истории Responses, изображения официальных участников, исходные патчи и восстановление моста/строки состояния.
- Интегрированы экспорт/импорт/перенос конфигурации, автозапуск, диктовка и совместимость Windows/macOS. Китайский, английский и русский переключаются без перезагрузки и записи черновиков с ключами.
- Сохранены все восстановленные функции AX, пять протоколов и контекст/сжатие каждой модели, независимый Anthropic на основе CC Switch, генерация изображений и фото/анимация/видео фон. Реклама и чужие значки не добавлены.

После установки полностью закройте старые Codex/Helper и запустите через AX. Удалять сессии или сбрасывать провайдеров не нужно. Шесть установочных файлов и `latest.json` публикуются после трёхплатформенных Actions. См. [отчёт](../reports/2026-10-22-upstream-v1101-sync.md).
