# Alunixa X v1.0.41 — 修复重复登录与图片/视频背景

> 未发布：正式门禁中的旧媒体静态断言失败；完整修复由 v1.0.42 交付，原标签保留。

## 中文

### 本版修复

- 修复高级自定义多模型供应商在启动时误走官方登录分支的问题：该分支会删除 `OPENAI_API_KEY`，导致管理器保存时认证正常、每次启动又回到登录界面。
- 启动时改用与管理器一致的 API 认证落盘规则，保留高级供应商的有效 Key，并兼容旧认证文件的 `auth_mode` 缺省情况。无效认证仍中止写入，不覆盖现有凭据；普通纯 API、混合、官方和聚合模式的策略不变。
- 删除仅支持内嵌 `dataUrl` 的过时图片初始化入口，在完整 renderer 初始化后接通现有图片/视频媒体运行时；恢复大图片、动画图片及视频的 File/Blob 运输、加载和播放。
- 保留透明度、适配方式、静音、暂停、循环、视频跳转、后台播放保护和退出清理，回收旧 Blob。保持严格 CSP，不开放任意文件、项目脚本、窗口捕获或系统代理。
- 保留 Anthropic 协议修复、逐模型协议/上下文窗口、高级供应商和已恢复的增强功能，不回退用户数据。

### 验证与使用

- 新增六项认证回归，包含真实启动 Hook、管理器/启动契约一致性、连续启动、代理准备、旧格式和错误凭据保护；当前已安装原生 Codex CLI `0.162.0-alpha.2` 在隔离目录里完成三次全新启动准备及全新 API 登录状态读取。
- 基于实际运行的 v1.0.40 与当前 Codex 窗口只读观察，确认媒体配置和文件有效，但旧启动路径没有创建媒体运行时；没有对用户正在使用的窗口热注入。
- 独立 Electron 运行完整生产 renderer 与真实 Rust 媒体桥，不手动执行首次媒体初始化，不使用会提前返回的组件测试标志。验证普通 PNG、大于 16 MiB 的 PNG、GIF、APNG、MP4、WebM、视频项目和旧静态预览，共九种媒体场景。
- 验证实际图片像素、动画变化、视频帧、跨块跳转/循环、暂停恢复、页面重新加载、前景输入、单实例和资源清理；故意失败用例必须退出 1，不能把加载事件或退出 0 当成完整通过。
- GitHub Actions 对 Windows x64、macOS x64、macOS arm64 执行完整回归、构建六项安装资产及 `latest.json`。
- 安装 v1.0.41 后，完整退出旧 Codex/Helper，再经 Alunixa X 启动；已运行的旧服务不会仅因保存配置而换成新代码。本次未自动安装或重启应用，没有更改真实账号、密钥、会话或系统代理。

## English

- Fixed advanced custom-model providers entering the official-auth cleanup branch at startup, which removed their API key and made Codex ask for login again.
- Startup now follows the same API-auth contract as the manager, including legacy missing `auth_mode`. Invalid credentials do not overwrite current files; other provider-mode policies are unchanged.
- Replaced the obsolete embedded-image-only bootstrap with the complete image/video runtime after renderer initialization. Restored File/Blob transport, large and animated images, video controls, and cleanup without weakening CSP.
- Preserves Anthropic conversion, per-model protocols/context windows, advanced providers, and restored enhancements.
- Six auth regressions and three fresh native Codex CLI `0.162.0-alpha.2` auth reads passed in disposable homes. Full-renderer Electron tests cover nine media cases, visible pixels, animation, real video frames, seeking/looping, pause/resume, reload, input, and teardown; no manual initial media install or early-return component test flag.
- GitHub Actions runs full regressions and packages Windows x64/macOS x64/macOS arm64. After installation, close the old Codex/Helper fully and relaunch through Alunixa X. No automatic installation/restart, live credential/session changes, or system-proxy edits.

- Устаревшая инициализация только встроенных изображений заменена полным медиарежимом после запуска renderer. Восстановлены File/Blob, большие и анимированные изображения, управление видео и очистка без ослабления CSP.
- Сохранены преобразование Anthropic, протоколы/контекст отдельных моделей, расширенные поставщики и восстановленные функции.
- Шесть проверок авторизации и три новых чтения состояния входа нативным Codex CLI `0.162.0-alpha.2` выполнены в временных каталогах. Полный renderer в Electron проверяет девять вариантов медиа, реальные пиксели/кадры, анимацию, перемотку/цикл, паузу, перезагрузку, ввод и освобождение ресурсов; первоначальная установка не вызывается вручную.
- GitHub Actions выполняет полные тесты и сборку Windows x64/macOS x64/macOS arm64. После установки завершите старые Codex/Helper и запустите приложение через Alunixa X. Автоматическая установка/перезапуск, изменение реальных ключей/сеансов и системного прокси не выполнялись.
