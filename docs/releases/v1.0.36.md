# Alunixa X v1.0.36

## 中文

### 完整非广告上游整合

- 固定上游 `BigPizzaV3/CodexPlusPlus@e53549ca8c2b2b1edf4199084460af0919f2ded4`，整合 2026-04-11 至 2026-10-12 的近半年更新：1,456 提交、656 文件；冲突采用新版架构并保留 AX 的配置事务和协议保真保护，不再仅同步少量补丁。
- 迁入新版双栏管理界面、统一 GUI/启动器、独立多开、Windows Claude 受管副本支持、全局 MCP/Skills、按需插件市场、语音输入、下一步建议多协议与提纲、打字特效、Whale 余额组件、缓存分类、CC Switch 导入、Grok/Zed 及模型元数据扩展。
- 同步会话索引与 SQLite 发现、原生浏览器恢复、排队跟进、用量生命周期、压缩 v2、渠道队列/RPM/冷却、工具模式和启动/配置兼容修复。
- 排除推荐广告页、供应商推广轮播、远程广告请求、主题推广链接和广告素材；保留正常社区主题、插件和扩展功能。

### AX 行为保留与整合修复

- 普通供应商及存量自定义模型保留五种逐模型协议；Claude `xhigh` / `ultra` 实际发送自适应思维，非法组合明确禁用。
- 修复压缩 URL 重复后缀和模型路由端点、无认证请求、重复自定义/会话请求头、工具 JSON Schema、消息与搜索 item ID。
- 客户端工具搜索映射为标准 function 并正确回放；原生服务端搜索不伪装为可执行工具。保留缓存创建/读取/TTL、思考统计原始值、工具身份及自包含签名回放，不以清空历史解决兼容问题。
- MCP 与插件关闭写入显式 false；供应商切换以当前原生能力和 Hook 信任为准，原始编辑仍允许撤销；合法多行 TOML 和数组表不被重新切分，损坏文本不会静默丢字段。
- 保留中英俄、图片/GIF/视频背景、生图模型默认项、配置修订检测/原子写入/备份/回滚、包上下文代理检查以及失败启动保活与恢复入口。

### 安装、验证与回退

Windows：安装 EXE 或完整解压 ZIP，保留 GUI 和 imagegen MCP 两个文件。macOS：使用与 CPU 架构匹配的 DMG/ZIP；本版只有一个可见 GUI 应用，旧双包安装通过安全手动迁移升级。发布提供六份安装资产和 `latest.json` 更新元数据，全部由本标签的 GitHub Actions 构建。

验证包含 Rust 回归、前端契约/TypeScript/生产构建、三语键完整性、真实 Chromium 的五协议保存、CustomModels 保存、生图排序与失败恢复、MCP 导航、窄窗以及安装器/updater 契约。具体最终数字以对应成功 Actions 和同步报告为准。

未声称已完成真实 Windows 首次白屏复现、Claude MSIX 安装、语音硬件、多开桌面及所有第三方网关参数验收；本轮未重启用户真实 Codex、清空会话或改动真实密钥。初始化失败不能当作链路在线。不兼容的不透明协议状态或不完整工具历史明确报错，而不静默降级。

回退可退出 AX 后重装 v1.0.35；保留配置事务生成的备份，按对应备份恢复受 AX 管理的配置文件，不整体删除 `.codex` 或覆盖用户后续会话。macOS 自动替换失败会保留/恢复旧应用；包代理备份需在原包上下文恢复。
