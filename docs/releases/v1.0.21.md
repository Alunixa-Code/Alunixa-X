# Alunixa X v1.0.21 · 动态壁纸、Wallpaper Engine 与对话配置修复

本版将 Codex 静态背景扩展为可上传的动态媒体与 Wallpaper Engine 项目，并修复 `features.guardianv2` 配置类型错误导致的新任务无法发送、旧任务无法恢复问题喵~

## 新增：动态壁纸上传与播放

- 打开 **皮肤管理 → 动态壁纸**，点击 **上传壁纸媒体**；原“设置”页也提供相同控件，支持预览、透明度、适配方式、静音、暂停与重置背景喵~
- 支持 GIF、APNG、动画 WebP，以及 MP4、M4V、WebM、MOV、OGV 视频；PNG、JPEG、BMP 和静态 WebP 继续作为静态图片，普通 PNG 不会自动生成动画喵~
- 媒体按原始字节复制到本机应用状态目录的 `wallpapers` 子目录，最大 2 GiB，不转码、不压平动画，也不修改原文件喵~
- 视频循环播放并通过 HTTP Range 流式读取，不将大视频编码进配置；具体解码能力取决于文件编码和内置浏览器，优先使用 MP4/H.264 或 WebM 喵~
- 切换或关闭背景时释放播放器、捕获流和资源；不可见时暂停视频，重新可见后按用户的暂停设置恢复，不遮挡输入和其他界面操作喵~
- 修复预览切换或卸载时异步播放取消被误报为解码失败的问题，导入失败不覆盖之前已保存的壁纸喵~

## 新增：Wallpaper Engine 项目目录

- 点击 **选择项目目录**，选择单个含 `project.json` 的壁纸目录，不是整个 Steam、Wallpaper Engine 安装目录或 Workshop 库喵~
- **Video** 项目使用项目指定的视频，按动态视频壁纸播放喵~
- **Web** 项目在隔离 iframe 中运行，允许项目内脚本、样式、图片、视频与 JSON/着色器资源，资源路由只读且限制在选定项目目录喵~
- **Scene** 项目在 Windows 上通过已安装的 Wallpaper Engine 打开独立命名渲染窗口，再将精确匹配的窗口捕获到 Codex 背景；兼容 `scene.json` 打包在 `scene.pkg` 内的 Workshop 项目喵~
- 可自动查找所选 Steam 库中的 Wallpaper Engine，也可手动指定引擎程序；不切换桌面壁纸，不捕获桌面或其他应用，关闭时仅清理自有壁纸窗口喵~
- 场景冷启动使用独立的有界等待，不再受普通 CDP 调用的 5 秒上限影响；找不到目标窗口时明确失败，不以 `preview.jpg` 冒充动态场景喵~

## 修复：新任务发送与旧任务恢复失败

- 修复无效 `features.guardianv2` 标量、结构化字段或嵌套字段引发的 `data did not match any variant of untagged enum FeatureToml`，覆盖普通表、inline table 和 profile 内对应配置喵~
- 保留有效的布尔开关、合法配置值、其他功能及注释，不用默认配置覆盖整个 `config.toml`，不删除任务记录喵~
- 修改前在对应 Codex home 的 `alunixa-x-config-repair-backups` 下保存原始 TOML；备份失败则不覆盖配置喵~
- 面板提供 **修复对话配置** 按钮，正常启动、保存设置与切换供应商也会经过兼容检查；保存供应商片段时同样校验，防止旧片段再次写回错误值喵~
- 修复后重新打开报错任务；其他 TOML 语法错误、项目级配置或其他来源的错误需要按实际报错文件处理，不将本次修复描述为覆盖所有配置问题喵~

## 使用与兼容边界

- 安装本版后保存壁纸设置，下次通过 Alunixa X 启动 Codex 时应用，不自动重启或热注入当前运行窗口喵~
- Scene 需要 Windows 与可用的 Wallpaper Engine，捕获上限为 1280×720、24 FPS；暂停控制 Codex 内的显示，不代表底层引擎渲染停机，场景声音由 Wallpaper Engine 独立窗口控制喵~
- 原生 Scene 已完成目录解析、脚本生命周期、精确窗口匹配和超时回归，但尚未进行真实 Wallpaper Engine → Electron → Codex 捕获链路的实机播放验收喵~
- Web 项目不能访问外部网络、Helper 其他接口、父页面 DOM、弹窗或启动程序；依赖 Wallpaper Engine 专有宿主接口或外部服务的项目可能无法完整运行，不保证所有 Workshop 壁纸兼容喵~
- 不执行 Application 类型壁纸；动态壁纸与 DreamSkin 皮肤包保持独立，重置背景不会重置供应商或任务数据喵~
- 本轮开发和发布未修改用户真实 `config.toml` / `auth.json`，未安装或重启用户的 Codex、Helper、CDP 或 Wallpaper Engine 喵~
