# Alunixa X v1.0.14 · 移除实验性上下文与残留配置

根据用户对重复开场、压缩后丢失任务的反馈，以及随后明确的“直接删除实验性上下文，Codex 配置中也不要保留”要求，本版彻底移除该功能，不再继续修补原有窗口切换链路喵~

## 删除内容

- 删除管理器的“实验性上下文”开关、默认值、设置字段及中英文说明喵~
- 删除本地 `context_notes` / `context_history` MCP 实现、token-budget 配置生成和保存笔记/主动切换窗口的提示模板喵~
- 图片生成 companion 仅保留图片生成，旧上下文启动参数不再启动服务喵~
- 删除已经退役的纯 API 上下文专项测试脚本及其 CI 官方 CLI 下载步骤，普通前端与完整 Rust workspace 测试继续执行喵~

## 清理配置并防止重新出现

- 仅删除 `features.token_budget` 整组、`features.context_management.experimental_mode` 及 `mcp_servers.alunixa-x-context`，包括配置 profile 中的同类覆盖喵~
- 管理器加载/保存、导入旧配置、切换供应商、正常启动与已有实例重新激活路径均清理退役项；公共配置和供应商保存的配置快照也会去掉退役项喵~
- 旧设置文件或旧客户端提交 `codexAppExperimentalContext` 不会再保存或重新启用功能喵~
- 清理前在用户配置目录内保存原始备份，重复执行不重复写文件；文件无效或检测到并发更新时停止覆盖，符号链接/重解析点不作为清理目标喵~

## 保留内容与生效范围

- 保留模型上下文长度、普通自动压缩 Token 阈值、Provider、凭据、其他 MCP、Fast 控件、中文界面与高级提示词恢复喵~
- 不删除旧笔记数据库、历史会话或工作记录，也不把已有笔记内容注入新任务喵~
- 安装新版本后打开管理器或通过 Alunixa X 启动 Codex 即会执行配置清理；已经运行的任务可能仍携带启动时加载的工具和提示，完整生效需在方便时重新启动 Codex，本版不会替用户强制重启当前实例喵~
- 本版移除有问题的增强机制，不承诺所有第三方模型或 Codex 原生压缩都绝不会遗忘；普通上下文处理恢复由 Codex 自身负责喵~

## 验证与发行

- 隔离回归覆盖删除后其他配置语义不变、boolean/点分/内联/profile 形式、BOM/CRLF、幂等、备份、无效输入、旧字段和旧供应商快照喵~
- Windows x64、macOS x64、macOS arm64 在正式 GitHub Actions 完整测试后锁文件构建，发布六项正式安装文件喵~
- 下文由正式流水线附加本版代码提交、Actions 来源与六项 SHA-256 喵~
