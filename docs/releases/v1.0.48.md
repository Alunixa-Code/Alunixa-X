# Alunixa X v1.0.48

## 中文

- 恢复 v1.0.42 的经典主界面、离线字体、面板和卡片样式，模型编辑在窄窗口下恢复为带字段标签的卡片。
- 修复“重启 Codex”只唤醒旧窗口的问题：使用当前会话实际分配的调试端口，不再把表单中的首选端口当作运行端口。
- 调试端点不可用时仍检查目标桌面进程；确认旧进程退出后才清理服务并重新启动，不再把“没有 CDP 响应”误当成“Codex 没运行”。
- Windows 重启按应用映像、命令行和进程句柄确认目标，不再全局结束所有 Codex；其他隔离实例和 CLI 不受影响。无法确认目标或退出失败时明确报错，不伪报重启成功。
- 保留新版全部业务能力：高级供应商、逐模型协议/上下文/压缩阈值、请求日志、代理设置、Agent 协作、Skills、MCP、增强与保存冲突保护。

本版按用户确认的范围只调整界面和主动重启，不改注入与托盘退出逻辑，不重置配置、账号、会话或媒体文件。安装后退出旧 AX 再打开新版；无须退回旧版数据。

## English

- Restores the v1.0.42 classic shell, bundled typography and card/panel styling. Narrow model editors use labeled cards again.
- Fixes Restart Codex only activating the old window: restart uses the session's actual debugger port rather than the launch form's preferred port.
- Checks the selected desktop process even when CDP is unavailable, then confirms its exit before cleaning up services and relaunching.
- On Windows, executable identity, command-line arguments and retained process handles scope termination to the selected desktop instance. Other isolated instances and CLI processes remain untouched; ambiguous targets and exit failures produce explicit errors.
- Retains all newer functionality, including advanced per-model providers/protocols/context/compaction, request logs, proxy settings, agent collaboration, Skills, MCP, enhancements and save-conflict protection.

This release changes only the interface and explicit restart, as requested. Injection and tray-exit behavior are unchanged. Configuration, accounts, conversations and media are not reset. Exit the old AX before opening the new installation.

## Русский

- Возвращены классический интерфейс v1.0.42, встроенные шрифты и оформление панелей/карточек. В узком окне редактор моделей снова использует карточки с подписями полей.
- Исправлен перезапуск Codex, который лишь показывал старое окно: используется фактический порт отладки сеанса, а не предпочтительный порт из формы запуска.
- Целевой процесс проверяется даже без доступного CDP; новый экземпляр запускается только после подтверждения завершения старого и очистки служб.
- В Windows проверяются исполняемый файл, аргументы и сохранённый дескриптор процесса. Другие изолированные экземпляры и CLI не завершаются. Неоднозначная цель или ошибка завершения сообщаются явно.
- Сохранены новые функции: расширенные провайдеры, протокол/контекст/сжатие каждой модели, журнал запросов, прокси, взаимодействие агентов, Skills, MCP, улучшения и защита от конфликтов сохранения.

По запросу изменены только интерфейс и явный перезапуск. Внедрение и выход через трей не менялись. Настройки, учётные записи, сессии и медиа не сбрасываются. Закройте старую AX перед открытием новой установки.
