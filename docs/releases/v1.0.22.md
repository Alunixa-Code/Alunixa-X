# Alunixa X v1.0.22 · 修复真实 Codex 壁纸显示与场景播放

本版针对 v1.0.21 用户实际反馈的“大图失效、视频不播放、Wallpaper Engine 场景不可用”修复运行链路，不再以构建成功、文件解析成功或创建覆盖层作为播放成功的依据喵~

## 修复内容

- **静态图与视频**：保留原图片/动图帧，大图和视频改用 Chromium 磁盘后备 `File → Blob URL`；媒体仅限当前选中文件，没有任意路径请求，不经被 Codex CSP 拦截的 localhost HTTP，也不把整个视频编码成 Base64，支持原生读取、Seek、循环、静音和暂停喵~
- **Wallpaper Engine Scene**：修正 Windows 对 `RAW~(...)~END` 属性 JSON 的参数转义，避免 `openWallpaper` 成功却在静音属性应用时退出失败；场景状态改走已有桥接，窗口捕获不再卡在 `Failed to fetch` 喵~
- **Wallpaper Engine Web**：使用 Wallpaper Engine 自身的独立窗口提供 Web 宿主环境，Codex 只接收画面；面板同步引擎路径、静音、暂停和平台条件，不再宣传实际被 CSP 拦截的 iframe 链路喵~
- **Web 黑屏路径修复**：传给原生引擎前规范化 Windows 扩展路径前缀，保留普通盘符/UNC 路径，避免引擎内置 Web 浏览器把 `\\?\` 路径转换为无效文件地址；不修改用户原始项目喵~
- **背景窗口与生命周期**：只对本次 UUID 命名的自有窗口去掉标题栏/边框和额外任务栏项，不切换桌面、不捕获其他窗口、不发送全局停止命令；关闭时仅回收自身位置喵~
- **恢复与错误信息**：启用 Page agent，正常页面导航后恢复注册脚本；切换或销毁时撤销 Blob、停止捕获轨道、移除临时 input，播放取消不再误报为解码失败，诊断区分“覆盖层已创建”和“媒体已真正解码”喵~
- **保留对话修复**：继续提供 `features.guardianv2` 的定向备份修复与供应商防回灌，不覆盖整个配置或删除任务记录喵~

## 使用方法与边界

1. 安装 v1.0.22，打开 **皮肤管理 → 动态壁纸**，上传图片/动图/视频，或选择单个包含 `project.json` 的 Wallpaper Engine 项目目录喵~
2. 对 Scene / Web 项目，确保 Windows 已安装 Wallpaper Engine；可从 Steam 库自动查找，也可手动指定 `wallpaper64.exe` / `wallpaper32.exe` 喵~
3. 保存后在合适时机通过新版 Alunixa X 启动 Codex；这次交付不会自动替换、刷新或重启你正在使用的 Codex / Helper，不必删除已有任务喵~

- 普通 PNG 仍为静态，GIF/APNG/动画 WebP 保留原动画；视频最大 2 GiB，解码能力取决于编码格式，优先 MP4/H.264 或 WebM 喵~
- Scene / Web 原生项目仅 Windows 支持且需要 Wallpaper Engine，捕获上限 1280×720、24 FPS；macOS 使用图片、动图、视频或 WE Video 项目喵~
- Web 项目的网络与宿主能力由 Wallpaper Engine 管理，项目脚本不进入 Codex 页面；不执行 Application 类型项目，不保证所有 Workshop 项目均兼容喵~
- 暂停控制 Codex 中的播放，不代表底层引擎完全停止；未修改用户真实 `config.toml` / `auth.json`，未在用户当前任务窗口热注入验证喵~

## 验证与发布

- 严格 `app://` CSP 的独立 Electron 验证覆盖静态 PNG、超过 16 MiB 的大 PNG、GIF/APNG 实际像素动画、MP4/H.264 跳转/循环/暂停恢复、WebM、WE Video、页面导航恢复、桥接共存和输入不被阻挡喵~
- 原生 Scene / Web 使用实际 Wallpaper Engine 的自有窗口，验证非黑内容、不同实际帧及截图，不用预览图或仅计时推进冒充场景效果喵~
- 原生 File 传输契约覆盖成功/失败清理、禁用拒绝及资源类型限制；前端、TypeScript、i18n、品牌、Rust workspace、全目标与格式检查作为发布门禁，第三方依赖版本保持不变喵~
- 正式 Windows x64、macOS Intel、macOS Apple Silicon 均由同一新标签在 GitHub Actions 运行完整回归并构建六项 GitHub Releases 安装资产，不复用旧版二进制；历史 v1.0.21 标签和资产不覆盖喵~
- 正式工作流在本说明末尾附加产品提交、Actions 来源和安装资产 SHA-256 喵~
