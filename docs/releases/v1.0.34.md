# Alunixa X v1.0.34 — Claude 请求兼容与自适应思维

## 中文

### 修复
- 修复新版 Codex 请求携带 `client_metadata` 时，本地转换器直接报 `unsupported request field client_metadata`；对象型客户端会话元数据不再作为非法模型参数，也不转发给不认识它的上游。
- 兼容历史助手消息的 `commentary` / `final_answer` 阶段，保留原文本；未知阶段、analysis channel、跨协议不可重放的加密思考仍明确报错，不偷偷删除历史。
- 修复 Claude 在 Chat Completions 转换中丢失推理强度。普通 `xhigh` 现在实际转发为 `reasoning_effort`，不再静默忽略。
- Anthropic Messages 支持当前 `xhigh` 枚举；旧 Opus 4.6 映射为 `max`、Sonnet 4.6 映射为 `high`。AX 的 `ultra` 映射为 `max`，不发送上游不认识的 Ultra 值。

### Claude 自适应思维
在管理器“模型最高思考等级”中，Claude 模型新增“自适应思维”。此模式覆盖该模型的线程推理强度，发送 `thinking: {"type":"adaptive"}`，不额外固定 effort 或 thinking token budget。

- 仅对 Chat Completions / Anthropic Messages 转换供应商开放，其他模型不显示；Responses、自定义多模型代理等不支持路径禁用该入口。
- Adaptive 只保存在 AX 设置中。生成的 Codex 模型目录使用合法的 low/medium/high 档位，不把 `adaptive` 写入 Codex 不支持的枚举。
- 自适应与固定 xhigh 是两种不同选择；模型可以按任务复杂度决定是否思考，不保证每次返回思考内容。
- 兼容网关仍须支持 `thinking` 扩展；AX 不声称每家网关都支持。

### 使用方法
1. 安装本版并退出旧版管理器/启动器。
2. 对上一轮现场返回 `convert_request_failed: not implemented` 的 Claude 供应商，使用 **Chat Completions** 协议，而不是该服务器尚未实现的 Responses 转换。
3. 在“模型最高思考等级”找到 Claude，选择“自适应思维”，保存后通过 AX 重新启动 Codex。
4. 其他模型可继续使用原供应商；不需要更换密钥或删除旧会话。跨协议旧会话若含不可重放数据，保留旧会话并新建会话验证。

### 验证与范围
- 本地定向 Rust 回归 124 项、前端 248 项、TypeScript、Vite 和英俄翻译检查通过；正式安装包由本次 GitHub Actions 生成。
- 同一实际服务器和 Claude 模型，以合成短消息、普通工具、`client_metadata` 和助手消息阶段，通过真实 AX 转换链路验证：固定 xhigh、自适应两种模式均 HTTP 200 且 `response.completed`；自适应响应包含缓存读取和创建统计。
- 缓存字段、策略和用量转换没有因本补丁而删改；不同工具/思考设置可能触发新的缓存创建。未替用户执行原始长会话，没有声称其全部历史已实测恢复。
- 本次不自动切换用户供应商、不修改正在运行的 Codex、不重置会话。回退旧版前，先将 Adaptive 改回旧版支持的固定档位并保存。

## Русский

Исправлены отклонение `client_metadata`, обработка фаз сообщений и потеря уровня рассуждения Claude в Chat Completions. Anthropic Messages теперь пропускает `xhigh`; для старых моделей 4.6 применяется совместимое значение, а `ultra` преобразуется в `max`.

В разделе максимального уровня рассуждения для Claude добавлено **«Адаптивное мышление»**. В режимах Chat Completions / Anthropic Messages оно отправляет `thinking: {"type":"adaptive"}` без фиксированного effort. В конфигурацию Codex не записывается неподдерживаемое значение `adaptive`. Другие модели и неподдерживаемые протоколы не получают эту настройку.

Для сервера с ошибкой Responses `convert_request_failed: not implemented` выберите **Chat Completions**, затем адаптивное мышление, сохраните и перезапустите Codex через AX. Ключи, провайдеры и сессии не удаляются. Перед откатом на старую версию сохраните обычный фиксированный уровень вместо Adaptive.

Оба режима проверены на реальном сервере с синтетическим коротким запросом через преобразователь AX: HTTP 200, завершённый ответ, статистика чтения и создания кэша сохранена. Исходная длинная сессия пользователя не воспроизводилась; совместимость всех шлюзов не гарантируется.

## English

Fixes rejection of Codex `client_metadata`, compatible assistant-message phases, and dropped Claude reasoning effort in Chat Completions. Anthropic Messages now accepts `xhigh`, maps older 4.6 models to compatible levels, and maps AX Ultra to Max.

Claude now has an **Adaptive thinking** option in the maximum reasoning-level screen. For Chat Completions / Anthropic Messages it sends `thinking: {"type":"adaptive"}` without a fixed effort or thinking-token budget. Adaptive stays in AX settings; generated Codex catalogs contain valid effort enums. Other models and unsupported protocols cannot select it.

For the investigated server returning Responses `convert_request_failed: not implemented`, select **Chat Completions**, choose Adaptive, save and relaunch Codex through AX. Existing credentials and sessions are preserved. Before downgrading, save a fixed reasoning level supported by the older AX version.

Both fixed xhigh and adaptive were exercised through the real AX converter against the configured server with synthetic short requests: HTTP 200 and completed responses, with cache creation/read accounting preserved. This does not claim full replay of the user's original conversation or universal gateway compatibility.
