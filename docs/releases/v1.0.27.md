# Alunixa X v1.0.27 — 管理器交互与加载体验优化

## 中文

v1.0.27 聚焦管理器本身的使用体验，优化了非日常界面的加载方式、全屏状态切换、键盘操作反馈、窄窗口布局和减少动效偏好喵~

### 本次更新

- 管理器部分低频界面改为按需加载，减少主界面首次加载负担喵~
- 优化全屏状态界面的层级、背景、转场、焦点和关闭行为喵~
- 增加 Escape 键退出、背景点击退出和操作后焦点恢复，避免界面状态无法返回喵~
- 优化窄窗口与 900px 级别宽度下的布局，并适配 `prefers-reduced-motion` 喵~
- 增加前端状态机、交互生命周期、本机轻量状态和多语言回归测试喵~
- 不升级第三方依赖，不修改真实 Codex 配置、认证信息、对话记录或用户媒体喵~

### 升级方式
- 本补丁同时整理低频界面资源的加载边界，不增加外部网络资源或第三方依赖喵~

1. 下载对应平台的完整 v1.0.27 安装包，或完整替换 ZIP 中的应用文件，不要混用不同版本文件喵~
2. 安装完成后，在方便时完全退出旧版 Alunixa X，再启动新版喵~
3. 本次更新不要求删除对话、模型目录、API Key、壁纸或整个配置目录喵~

### 验证范围

- 管理器前端测试：122 passed / 0 failed 喵~
- TypeScript、Vite、英文/俄语词典、品牌和格式检查通过喵~
- 独立 Chromium UI 验收覆盖 1440×900、900×680、中文、英文、俄语、Escape、重复探索、减少动效和页面错误检查喵~
- 正式 Windows x64、macOS x64、macOS arm64 构建与六项安装资产由 GitHub Actions 完成喵~
