# Alunixa X v1.0.32 — Codex 26.924 白屏兼容修复

## 中文

- 修复 DreamSkin 在 Codex/ChatGPT Desktop 26.924.x 中把整条对话容器误当顶部渐变遮罩并设置 `display:none` 的问题；现仅隐藏实际 top-fade 元素，首页、历史对话和输入框不会再因皮肤塌成 `0×0` 喵~
- 修复新版 Codex 调整 renderer 分块后 dispatcher 只按旧资源名前缀查找的问题；优先使用 `app-shared`，必要时在已加载的应用分块中执行有界兜底发现，不扫描或加载全部资源喵~
- dispatcher 兼容失败保持可选降级和有限重试，不把增强补丁失败当成 Codex 原生界面已失败，也不因该错误终止桌面进程喵~
- 保留启动时重新应用管理器供应商配置、首选模型和应用包实际代理视图的行为，不清空用户会话、密钥或全部持久化状态喵~
- 增加 Windows/macOS 相同样式哈希、危险选择器负向检查和 renderer dispatcher fallback 回归喵~
- 保留 v1.0.31 的非广告上游同步、每次启动配置覆盖和应用包代理覆盖喵~

## Русский

Исправлена белая/пустая область в Codex Desktop 26.924.x: DreamSkin больше не скрывает весь контейнер диалога вместо верхнего градиента. Поиск dispatcher теперь поддерживает новые разделённые renderer-модули и ограниченный fallback по уже загруженным ресурсам. Перед каждым запуском по-прежнему применяются выбранная конфигурация и proxy-view приложения без удаления сессий и ключей喵~

## English

Fixes a Codex Desktop 26.924.x blank-content failure where DreamSkin hid the entire conversation container instead of the top fade. Dispatcher discovery now supports the split renderer layout with a bounded fallback over already-loaded app bundles. Selected configuration and the packaged-app proxy view are still reapplied before every launch without deleting sessions or credentials喵~
