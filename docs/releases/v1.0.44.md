# Alunixa X v1.0.44 — PR #1 优化与 macOS DMG 打包修复（未发布候选）

## 中文

- 交付 PR #1 的 Fast 服务模式初始化与原生模型菜单适配优化。
- 失败读取会在后续成功心跳重试；重新注入或 native client 替换会清理旧 JSX wrapper；支持已核验的 Codex `26.1007.2314.0` 与 `26.1007.30912`，未知版本保留 fallback。
- 修复 macOS x64 DMG 打包在 Finder 对中文隐藏应用执行 `set visible` 后无法 detach 的问题；隐藏应用继续通过 `.hidden` 和 `chflags hidden` 处理，不依赖 Finder 逐项可见性命令。
- 完整 workspace、前端、安装器和三平台正式 Actions 回归通过后发布六项安装资产及 `latest.json`。
- v1.0.43 候选未发布，仅保留其失败标签作为历史记录；本版包含全部代码修复。
- v1.0.44 候选随后又被旧 `windows_subsystem.rs` Finder 静态断言拦截，未发布；完整交付由 v1.0.45 完成。

## English

- Ships the reviewed and hardened PR #1 Fast bootstrap and native model-picker adapter.
- Failed reads retry on later successful heartbeats; reinjection and native-client replacement dispose stale JSX wrappers; verified Codex `26.1007.2314.0` and `26.1007.30912` are supported while unknown versions keep the fallback.
- Fixes macOS x64 DMG packaging failing to detach after Finder attempted `set visible` on the Chinese hidden app. The app remains hidden through `.hidden` and `chflags hidden`, without per-item Finder visibility commands.
- Full workspace, frontend, installer, and three-platform Actions gates produce six installers and `latest.json`.
- The v1.0.43 candidate was not published; this release contains all code and packaging fixes.
- The v1.0.44 candidate was then blocked by an obsolete `windows_subsystem.rs` Finder assertion and was not published; v1.0.45 delivers the complete fix.

## Русский

- Выпущены проверенные и усиленные Fast bootstrap и нативный выбор модели из PR #1.
- Ошибки чтения повторяются на следующих успешных heartbeat; при повторной инъекции и замене native client старый JSX-wrapper освобождается; проверенные Codex `26.1007.2314.0` и `26.1007.30912` поддерживаются, неизвестные версии используют fallback.
- Исправлена упаковка macOS x64 DMG: Finder больше не выполняет нестабильный `set visible` для скрытого приложения с китайским именем. Скрытие сохраняется через `.hidden` и `chflags hidden`.
- Полные workspace/frontend/installer и три платформы Actions проверены, опубликованы шесть установочных файлов и `latest.json`.
- Кандидат v1.0.43 не публиковался; этот выпуск содержит все исправления кода и упаковки.
- Кандидат v1.0.44 затем был остановлен устаревшей проверкой Finder в `windows_subsystem.rs` и не публиковался; полный выпуск выполняется в v1.0.45.
