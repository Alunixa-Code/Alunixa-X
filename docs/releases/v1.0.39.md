# Alunixa X v1.0.39 — 恢复供应商高级配置与增强功能

## 中文

### 本版修复

- 恢复供应商列表的 **添加供应商(可自定义)** 直达入口，并在新供应商选择页提供同一入口；不再要求先创建普通供应商、再寻找隐藏的模式选择。
- 恢复完整的独立多模型编辑：每个模型的 Base URL、API Key、五种协议、上下文窗口、自动压缩开关/Token 阈值、最高思考等级与 Claude 自适应思维、默认启动模型、拖拽/键盘/上下移动排序和单模型连接测试。保存后自动显示该供应商所在分区，重开与重新加载保留配置。
- 增加名称、重复模型、地址、协议、窗口与压缩阈值校验；无效草稿不静默写入，也不删除其他模型。保持上下文配置和供应商数据隔离。
- 补回升级前增强页的已实现控制与设置类型：Agent 健康检查、应用包代理自动修复、Windows Computer Use Guard、插件全量展示/缓存修复、项目移动、Instructions、记忆嵌入、AI Shell/共享终端/释放时间、语言、快速启动、更新控制、WSS、性能保护、原生菜单、Zed 与 upstream worktree；保留新版语音、下一步建议、回答大纲、打字特效和原生浏览器设置。
- 原生 Fast/Goals/WSS/子代理数量读取真实审计结果，只有明确编辑的配置项进入修订号保护的保存队列；不因保存其他设置覆盖原生参数。同步 Zed settings 原本未实现，仍明确禁用，不以开关冒充支持。
- 不只恢复按钮：重新接通相应的后端、Hook、原生注入和请求路由。共享终端的 CLI HTTP 提交与 renderer CDP 桥使用同一实例的 broker，保留命令结果、心跳、退出清理和停止保护；不关闭用户自己的原生终端，不自动重放不确定命令。
- 恢复语言/启动/性能注入及原生菜单、更新策略与 Guard 的实际启动链路；禁用或重新启用时回收自己的订阅和补丁，保留用户后续修改。兼容增强模式保留设置，但不执行完整模式的插件请求改写。
- 恢复 Responses ID 协商开关的实际 HTTP 入口，仅在明确的 400/422 输入拒绝及可识别前缀错误时修正一次；失败、已输出或结果不明的请求不借此重放。
- 恢复官方手机远控与浏览器/设备码登录、配对检查/设备撤销、Zed 远程项目记录和本机 Token/模型用量页面；登录后重新读取设置，防止旧界面快照覆盖新的账号配置。
- 保留 v1.0.38 基于 CC Switch 的 Responses ↔ Anthropic 原生转换，以及新版管理器、独立供应商、MCP、Skills、壁纸、生图、三语、安装器和配置事务保护；不回退上游整合，也不恢复广告/赞助页面。

### 验证与使用

- 以升级前 v1.0.35 对照 v1.0.38 建立功能清单，覆盖旧增强字段和对应后端入口；既有“功能退役”测试按恢复后的真实契约重新验证，保留失败、所有权、平台和安全边界断言。
- 真实 Chromium 验证从空白入口新建两个独立模型，设置不同协议/窗口/地址/密钥、压缩、默认项、排序及思考等级，保存、重开、重新加载；增强保存不会丢失其他供应商，原生写入集合也单独校验。
- 本机临时 HTTP/CDP/broker 与文件夹具验证共享终端、签名/协议、窗口、配置保留和启动链路；正式 GitHub Actions 对 Windows x64、macOS x64、macOS arm64 执行全部测试并构建六安装资产和 `latest.json`。
- 不清空用户会话、供应商、密钥或配置，不自动安装或重启正在运行的 Codex，也不修改系统代理。安装后完整退出旧实例，再经 Alunixa X 启动。原生能力和账号远控的实际可用性仍由已安装 Codex 与账号支持决定，未以真实账号执行登录/退出或远控变更。

- Explicit native capability edits enter the revision-protected save queue; unrelated settings no longer overwrite native options. Shared-terminal HTTP submissions and renderer bridge operations share an instance-scoped broker, with cancellation, lifecycle cleanup, and no uncertain command replay.

- Restored official mobile remote control, browser/device-code sign-in, pairing/device management, Zed projects, and local token/model usage. Authentication changes refresh the settings revision before subsequent saves.

Install the release, exit the old instance, and relaunch through Alunixa X. Previously unimplemented Zed settings synchronization remains visibly unsupported.
