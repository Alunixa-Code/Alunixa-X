# Alunixa X v1.0.43 — Fast 控件与原生模型菜单优化

## 中文

### 本版修复

- 集成并优化 PR #1 的 Fast 服务模式初始化和原生模型菜单适配。
- 后端设置加载完成后立即读取服务模式；如果首次读取失败，后续成功的心跳会自动重试，不需要重新打开增强设置页。
- 原生 Fast 适配仅对 API-key、本地连接、后端就绪、支持 Fast 的模型和已核验的 Codex `26.1007.2314.0` / `26.1007.30912` 合同启用；其他版本继续使用 Alunixa 控件。
- 重新注入或本地 native client 替换时，先卸载旧 JSX wrapper、使旧请求失效，再安装新适配，避免旧组件闭包残留。
- 保留已有线程/草稿服务模式覆盖、模型支持判断、配置要求 `fast_mode=false` 禁用语义、官方登录和远程连接的 fallback。
- 不修改认证身份、订阅权限、官方应用包或系统代理，不把 Fast 展示误报为供应商实际计费或速度保证。

### 验证

- PR 原始提交：前端 `694 passed / 1 skipped`。
- 优化后前端：`698 passed / 1 skipped`，TypeScript、Vite、i18n、renderer assembly、品牌、安装器和格式检查通过。
- Rust 定向：`cdp_bridge 163`、`protocol_fidelity 35`、`protocol_proxy 161` 全部通过。
- Rust workspace：`cargo test --workspace --locked --no-fail-fast -j3 -- --test-threads=1` 退出 0，所有结果无失败。
- GitHub Actions 对 Windows x64、macOS x64、macOS arm64 执行完整回归并生成六项安装资产和 `latest.json`。

> v1.0.43 候选的 macOS x64 DMG 打包门禁发现 Finder 对中文隐藏应用的可见性命令不稳定；修复由 v1.0.44 交付，v1.0.43 标签保留但未发布。

## English

- Integrated and hardened PR #1's Fast service-tier bootstrap and native model-picker adapter.
- Service-tier state loads after backend settings initialization and retries on later successful heartbeats after a failed read.
- Native adaptation is limited to API-key local sessions, ready backends, Fast-capable models, and the verified Codex `26.1007.2314.0` / `26.1007.30912` component contract. Unknown versions keep the Alunixa fallback.
- Re-injection and native-client replacement dispose old JSX wrappers and invalidate stale work before installing a new adapter.
- Existing thread/draft overrides, model checks, `fast_mode=false` requirements, official-auth fallback, and remote behavior remain intact.
- No authentication, subscription, official package, or system-proxy changes are made.
- The optimized suite passes 698 frontend tests with one existing skip, targeted Rust bridge/protocol suites, and the full locked Rust workspace. GitHub Actions builds Windows x64, macOS x64, macOS arm64, six installers, and `latest.json`.
