# Alunixa X v1.0.12 · 中文界面与启动兼容修复

本版本只发布到 **Alunixa-Code/Alunixa-X** 新仓库，保留 v1.0.11 的高级提示词恢复、供应商、微信、仪表盘及纯 API 本地上下文能力喵~

## 修复已选中文但页面仍为英文

- 根据 Codex `26.901.5280.0` 安装资源只读审计，新版语言 Provider 改用 Statsig `getLayer("72216192")`，旧补丁仅处理 `getDynamicConfig()`，导致选中中文但内置语言消息未启用喵~
- 现在兼容新旧两种入口，仅处理语言配置，保留其他 Layer、实验、模型与权限配置；冻结的语言结果也不再妨碍兼容处理喵~
- 慢启动的客户端和桥接会在有限窗口内继续发现与重试，接口调用失败会清理监听器并退避，不再一次失败就静默放弃喵~
- 对已经挂载、缓存旧语言对象的界面，必要时只自动刷新一次；按版本和目标语言保存刷新标记，存储不可用时推迟刷新而不是不断重载喵~

## 保留用户选择与可恢复性

- 关闭强制中文后恢复 navigator 和原始语言 API，恢复此前语言设置，包括“自动检测”的空值喵~
- 如果用户后来在 Codex 内手动选择了另一种语言，关闭增强不会把该选择覆盖回旧值喵~
- 更改开关会取消旧的异步同步请求；无效设置响应、原语言备份失败时不会覆盖正式设置喵~
- 已有高级提示词正文、last-good 备份、模型、Provider、MCP、权限模式及当前任务没有因本次语言修复而改动喵~

## Ultra 提示调查结果

- 当前 Codex 将“启用完全访问”和“Ultra 与完全访问组合使用”作为独立确认，后者同时提供改用受限权限的选择喵~
- **本版保留这些原生确认，不实现 Ultra 自动提权、全局自动点击确认或永久绕过授权**，不将这项用户请求描述为已经完成喵~

## 验证与安装

- 新增十三项隔离行为回归，覆盖新旧 API、冻结对象、慢启动、重复注入、单次刷新、存储异常、设置格式、关闭恢复、用户新选择与异步取消；完整前端共 66 项喵~
- 正式 Actions 在 Windows x64、macOS x64、macOS arm64 执行完整前端和 Rust workspace 测试，锁文件构建后发布六项平台安装文件喵~
- Windows 继续保留本版 companion 与固定官方 CLI 的纯 API 原生窗口隔离验证，不操作用户正在运行的 Codex、helper、CDP 或真实提示词喵~
- 安装 v1.0.12 后，保持管理器中的“强制中文界面”开启，并通过 Alunixa X 重新启动 Codex；本次未直接修改或重启当前实例喵~
- 六项安装文件的构建提交、Actions 来源与 SHA-256 由正式流水线附在下文喵~
