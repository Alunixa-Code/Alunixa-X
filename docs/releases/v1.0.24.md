# Alunixa X v1.0.24 — 正式启动器壁纸接口与场景弹窗修复

## 这次修复的实际问题

v1.0.22/v1.0.23 的隔离壁纸测试接通了媒体接口，但正式使用的数据启动器没有接入相同路由，真实日志返回 `Unknown bridge path`；因此管理器预览成功、构建通过或 Wallpaper Engine 已经启动，都不代表 Codex 背景已经显示喵~

原生 Scene/Web 需要引擎提供画面，但旧版直接创建可见的 `-playInWindow` 窗口，随后仅置底；这不是用户需要手动操作的额外窗口，也不等于真正隐藏喵~

## 修复与改动

- **统一正式分发入口**：核心启动器、正式数据启动器及 Electron 实播程序统一调用 renderer bridge 安装函数；`/wallpaper/media` 与 `/wallpaper/scene` 不再掉进通用路由的未知接口分支喵~
- **保留图片与动态媒体**：普通图片使用原有覆盖层；大图、视频及 Video 项目继续通过仅限已选媒体的磁盘后备 File/Blob 播放，不放开 Codex CSP，不把整段视频转成 Base64 喵~
- **场景不再作为可见弹窗出现**：使用 Wallpaper Engine 官方坐标参数，从创建时就把自有窗口放在所有显示器左侧的离屏位置；移除任务栏项和边框、不激活，也不最小化导致渲染停止喵~
- **收紧失败处理**：启动前先同步发布 waiting 状态，避免首次请求与后台初始化竞争；离屏布置失败时，只关闭本次 UUID 名称对应的窗口，不控制其他壁纸或桌面喵~
- **修复验证盲区**：增加真实 WebSocket 的生产入口分发、禁用保护、错误资源类型及普通路由共存回归；增加两个正式启动器与 fixture 使用统一入口的防退化检查喵~
- **实播同时检查窗口行为**：除图片解码、GIF/APNG 帧变化、MP4 跳转/循环、WebM、原生非黑画面及动画外，额外检查 Win32 实际窗口坐标、任务栏样式、焦点和最小化状态喵~
- 更新中文、英文、俄文 README 与壁纸指南，纠正旧版“测试通过等于正式链路可用”的说明，并明确保留只使用图片背景的方式喵~

## 如果只想使用原来的图片背景

在 **皮肤管理 → 动态壁纸** 上传 PNG/JPEG/BMP/静态 WebP 即可，按原方式设置透明度和适配模式；这条路径不依赖、不启动 Wallpaper Engine，也不要求启用视频或场景喵~

## 升级与生效

1. 安装本版，或完整解压本版 Windows ZIP，确保启动器、管理器和配套程序来自同一版本喵~
2. 保存壁纸设置，在方便时退出旧 Codex，再通过新版 Alunixa X 启动；只打开新版管理器不会让已运行的旧进程自动加载新代码喵~
3. 不需要删除任务、重新配置供应商或重置所有设置；俄语界面、已有 guardianv2 定向修复等功能保留喵~

Scene/Web 仍仅支持 Windows 并需要已安装的 Wallpaper Engine，捕获上限为 1280×720、24 FPS；引擎会在后台渲染，暂停只暂停 Codex 显示，具体音视频能力仍取决于项目和编码喵~

## 构建与验证范围

- 新标签通过唯一 GitHub Actions 运行，对 Windows x64、macOS x64/arm64 分别执行完整测试、编译和打包，再发布六项安装资产；源码、构建来源及 SHA-256 由工作流附在下方喵~
- 本地使用独立 Electron、临时媒体/配置和用户已选择的原生项目验证，不热注入或重启用户正在运行的 Codex，不修改真实配置、原始媒体或桌面壁纸喵~
- 不升级第三方依赖，不移动旧标签，不覆盖历史发行资产喵~

## Русский

В v1.0.22/v1.0.23 реальный лаунчер не подключал маршруты обоев и возвращал `Unknown bridge path`, хотя отдельный тест работал. Теперь оба лаунчера и тест используют одну точку подключения: исправление применяется к реальному пути запуска, а не только к тестовой среде.

Нативные Scene/Web запускаются за пределами всех мониторов, без отдельного видимого окна, элемента панели задач и активации фокуса. Окно не сворачивается, чтобы движок продолжал отдавать кадры. Захватывается только окно с уникальным именем; рабочий стол и чужие окна не затрагиваются.

Проверки дополнены настоящими запросами WebSocket и проверкой координат/стилей окна Win32 вместе с непустыми меняющимися кадрами. Сохранены изображения, видео, анимация, русский интерфейс и исправление конфигурации guardianv2; обновлены руководства на трёх языках.

Если нужен только обычный фон, импортируйте PNG/JPEG или другую статичную картинку — Wallpaper Engine не требуется и не запускается. Для применения обновления полностью замените файлы программы и при удобном случае заново запустите Codex через новый Alunixa X; задачи и настройки удалять не нужно.

Scene/Web требуют Windows и установленный Wallpaper Engine. Движок продолжает работать в фоне; предел захвата — 1280×720, 24 FPS. Все шесть установочных файлов собираются заново в GitHub Actions из одного тега.
