# Alunixa X v1.0.13 · Fast 按钮布局兼容修复

本版本发布到 **Alunixa-Code/Alunixa-X** 新仓库，保留中文界面修复、高级提示词恢复、供应商、微信及纯 API 本地上下文能力喵~

## 已修复：更新 Codex 后 Fast 按钮消失

- 只读核验的 Codex 版本为 `26.901.6511.0`，新版输入栏底部使用 `_ComposerFooter_*` / `_ComposerLayoutFooter_*` CSS 模块类名及 `data-composer-footer-responsive`，旧补丁只查找 `.composer-footer`，因此找不到挂载位置喵~
- 现在同时支持旧版、共享 footer 和新版紧凑/多行输入栏，不依赖完整的哈希类名；即使关闭 footer 的 responsive 属性，CSS 模块结构也能被识别喵~
- 挂载优先选择实际 footer，排除隐藏或已经移除的输入栏，避免按钮挂到其他工具栏；输入栏重新渲染后会恢复单个控件喵~
- 不再把 Fast 控件嵌入原生按钮中，也不会重复绑定事件、生成多个控件或反复将控件插入自身之前喵~
- 新版 footer 的 DOM 变化会进入已有的有界刷新路径，扩展自己的 UI 变化仍不会递归触发全量扫描喵~

## 保留现有设置和能力判定

- 保留“Fast 按钮”开关及默认关闭策略，不覆盖用户主动关闭的选择喵~
- 后端未连接时控件继续显示状态，并设置 `aria-disabled`；不把断开连接误报为 Fast 已启用喵~
- 原生 `model/list` 的 `serviceTiers`、受支持模型判定、当前任务和全局服务模式策略保持原样，不盲目给未知模型设置 `priority` 喵~

## 未包含：Ultra 一次确认后记住

- 本次核对了原生 Ultra 与完全访问组合提示，但**没有实现“确认一次后记住”**，也不将这项请求计入修复结果喵~
- 原生首次确认、取消、切换受限权限和 Guardian 分支保持不变，没有添加自动点击、程序代答或全局权限回调拦截喵~

## 验证与安装

- 新增十一项隔离前端行为回归和一项 Rust 安装资源嵌入契约，完整前端 `77/77`、TypeScript 和生产构建在本地验证喵~
- 正式 GitHub Actions 在 Windows x64、macOS x64、macOS arm64 执行完整 Rust workspace 和前端测试，再锁文件构建六项正式安装文件喵~
- Windows 保留正式 companion 与固定官方 CLI 的纯 API 原生窗口隔离端到端验证喵~
- 本次没有连接、修改或重启用户正在使用的 Codex、helper、CDP、微信或真实配置；实机当前实例的显示效果不在本地验证范围内喵~
- 安装本版后，确保管理器中 Agent 能力的“Fast 按钮”已开启，并在方便时通过 Alunixa X 重新启动 Codex 才会应用新补丁喵~
- 本次构建提交、Actions 来源和六项 SHA-256 由正式流水线附在下文喵~
