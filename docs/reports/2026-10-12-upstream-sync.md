## 修复与证据

- 压缩端点重复后缀、路由丢失、无认证请求与重复自定义/会话头，在本地 HTTP fixture 中复现并修复；工具 Schema 与 msg_/tsc_ 身份同步新版协议。
- Claude 的 xhigh/ultra（包括显式 reasoning_effort）实际为 adaptive；客户端 tool_search 转成标准 function 并恢复 search item，不把服务端搜索伪装成客户端执行。
- JSON/SSE、缓存与签名使用 AX 严格保真回归；结果不明不进行不安全重放，跨协议 opaque state 不当成明文。
- 有效 TOML 多行字符串/数组表先整体解析，不按伪表头切开；损坏文本保留并给出错误。旧关闭后删除字段的行为改为明确关闭，避免缺省重启。
- Windows multi-worker 中 directories 的 Known Folder API 不按 HOME 选主目录；已增加 ALUNIXA_X_STATE_HOME、worker options 父目录校验，主实例设置/日志/状态不会借用。
- SQLite 发现补齐根目录 state_N 和 catalog-only 数据库，并沿用只读表检查，不创建/修改不存在的候选数据库。
- 旧共享终端 Hook 引用已不存在的 /shared-terminal/submit，现停止生成失联代理命令，保留原命令和当前 AI Shell；对应旧偏好不删除，新的扩展运行时按新版路径使用。
- 应用隔离代理问题的现场证据来自用户已确认的 Silo 读取与禁用结果，最初写入者尚未确定；未把它无证据归因于 AX。启动覆盖与针对性失效代理修复是不同策略，前者开启后会将包视图 ProxyEnable 写为0，后者保留正常代理。
